# Ayatsumugi for Zed

This is a real Zed extension scaffold that launches the separately distributed
`ayatsumugi-mcp` sidecar in the Agent Panel. Zed does not currently expose an
arbitrary Webview/sidebar API, so the interactive graph is opened as a local
browser report through the task examples in this directory.

Install this directory with **Zed: Install Dev Extension**. Install the signed
Ayatsumugi sidecar separately and make `ayatsumugi-mcp` and `ayatsumugi`
available on `PATH`.

The sidecar is not included in this Apache-2.0 repository.
