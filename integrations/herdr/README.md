# Ayatsumugi for Herdr

Install after the repository is published:

```sh
herdr plugin install nkwork9999/ayatsumugi-herdr
```

Use **Ayatsumugi: Check runtime** or open the **Ayatsumugi: Inspect** pane. The plugin delegates to the public terminal adapter and requires the private sidecar on `PATH` or in `AYATSUMUGI_MCP_BIN`.
